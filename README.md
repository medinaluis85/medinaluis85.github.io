# medinaluis85.github.io

Domain-root Pages site for medinaluis85. Hosts:

- **`app-ads.txt`** — the AdMob publisher-authorized file for the **Dinner
  Truce** Android app (publisher ID `pub-2545624803129852`). AdMob crawls the
  developer-website DOMAIN ROOT, and every site under
  `medinaluis85.github.io` shares this root, so the file lives here.
- A small landing page (so the root does not 404).

The app lives in the private `dinner-picker-android` repository; its privacy
policy is published at
<https://medinaluis85.github.io/dinner-truce-privacy/>.

## If the publisher ID ever changes

Update `app-ads.txt` here FIRST, then the AdMob app record — the file must
agree with the account it points at.
